Projet 1 : Infrastructure pour 480 Postes

Un projet majeur de conception d'infrastructure informatique pour une grande entreprise pharmaceutique. Déploiement de 480 postes de travail sécurisés avec un réseau hautement segmenté.

🎯
Le Défi
Équiper 480 visiteurs médicaux avec des postes de travail sécurisés, fiables et bien organisés, avec un budget limité (299€/poste).
⚙️
Notre Solution
Création d'une infrastructure avec 12 VLANs pour segmenter le réseau, gestion centralisée via Active Directory, et déploiement automatisé des postes.
✅
Les Résultats
480 postes déployés avec succès, budget respecté exactement, zéro incident depuis le déploiement en production.

Technologies utilisées : Windows 11 Pro • Active Directory • Cisco Switches • VPN/Firewalls • WDS/MDT

Projet 3 : Veille Technologique - NASLE

Analyse approfondie d'un logiciel révolutionnaire basé sur l'Intelligence Artificielle : NASLE, un système de vidéoprotection intelligente.

🤖
C'est quoi NASLE ?
NASLE est un logiciel de vidéoprotection nouvelle génération développé par Nepsis Engineering. Il utilise l'IA et la vision par ordinateur pour analyser les flux vidéo en temps réel et détecter automatiquement les situations dangereuses ou anormales.

Capacités principales :

  • 🚨 Détection de violence : agression, bagarres, personnes à terre
  • 🔥 Détection d'incendie : départs de feu et fumée
  • 👥 Comptage de personnes : regroupements suspects ou dépassement de seuils
  • 🔫 Détection d'armes : pistolets, couteaux et autres objets dangereux
  • 📊 Comptage de trafic : analyse des mouvements piétons et véhiculaires

🔄 Migration Windows 10 → Windows 11
2024 - 2025 PDQ Deploy Automatisation Enterprise

Contexte : Microsoft mettra fin au support de Windows 10 le 14 octobre 2025. La mairie devait migrer l'ensemble de son parc informatique avant cette date limite. C'est un projet critique impactant 300+ utilisateurs.

Mes actions :

  • 🔍 Audit complet du parc : vérification de la compatibilité matérielle (TPM 2.0, Secure Boot, RAM, stockage)
  • ⚙️ Automatisation du déploiement : configuration de PDQ Deploy pour des mises à jour sans intervention manuelle
  • 📦 Création de packages : préparation des images système optimisées avec les logiciels nécessaires
  • 🧪 Tests pilotes : migration test sur 10 postes avant déploiement général
  • 📞 Support utilisateur : assistance 24/7 pendant la migration
  • 📚 Documentation : guides complets pour les futures migrations

Résultats : ✅ 300 postes migrés • ✅ 0 incident critique • ✅ 100% de réussite • ✅ Gain de temps : 70% plus rapide qu'une migration manuelle
