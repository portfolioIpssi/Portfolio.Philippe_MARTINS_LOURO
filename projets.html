1️⃣ Infrastructure pour 480 Postes (SISR)

Projet majeur : conception d'infrastructure informatique pour une entreprise pharmaceutique. Déploiement de 480 postes sécurisés.

🎯
Le Défi
Équiper 480 visiteurs médicaux, budget limité (299€/poste), réseau segmenté par services.
⚙️
Solution
12 VLANs, Active Directory centralisé, déploiement automatisé, sécurité.
✅
Résultats
480 postes déployés, budget respecté, zéro incident.

🔧 Tech : Windows 11 • Active Directory • Cisco • VPN • WDS
