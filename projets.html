2️⃣ Homelab — Infrastructure Personnelle 🖥️

Conception et déploiement d'une infrastructure réseau personnelle composée de 3 machines physiques, avec virtualisation, services auto-hébergés, VLANs et sécurité avancée. Un véritable lab pour apprendre l'administration système et réseau en conditions réelles.

Dell OptiPlex — Always-On Acer PB63 — Hyperviseur Acer Nitro — Workstation
🌐
Réseau & Sécurité
Switch manageable, VLANs isolés, Pi-hole DNS, Wireguard VPN, IDS/IPS, Wazuh SIEM.
🖥️
Virtualisation
Proxmox VE sur Acer PB63 : 4 à 6 VMs/conteneurs LXC — Nextcloud, Gitea, Jellyfin, CI/CD.
☁️
Services auto-hébergés
Nextcloud, Vaultwarden, Jellyfin, Grafana, Home Assistant — 100% sur serveur local.

🏗️ Architecture réseau

── Topologie physique & logique ────────────────────── INTERNET │ [Box FAI] │ [Switch manageable TL-SG1005P V2] / | \ / | \ [Dell OptiPlex] [Acer PB63] [Acer Nitro] Pi-hole / DNS Proxmox VE PC Perso Wireguard VPN Nextcloud Monitoring Jellyfin Home Assistant Vaultwarden Wazuh SIEM VLAN 10 : Réseau VLAN 20 : VMs VLAN 30 : Perso

⚙️ Services déployés

  • 🔒 Pi-hole + Unbound — Blocage DNS des pubs sur tout le réseau, résolveur récursif local
  • 🔑 Wireguard VPN — Accès sécurisé au réseau depuis l'extérieur (chiffrement AES-256)
  • 📊 Prometheus + Grafana — Monitoring CPU, RAM, réseau de toutes les machines
  • 🏠 Home Assistant — Domotique centralisée
  • 📁 Nextcloud — Alternative à Google Drive/Photos, auto-hébergée
  • 🔐 Vaultwarden — Gestionnaire de mots de passe (compatible Bitwarden)
  • 🎬 Jellyfin — Serveur de streaming média (films, séries, musique)
  • 🛡️ Wazuh SIEM — Centralisation et analyse des logs de sécurité
  • 🗂️ Gitea + Woodpecker CI — Forge Git et pipeline CI/CD privés

🗺️ Plan de mise en œuvre

1️⃣
Phase 1 — Base réseau
Ubuntu Server sur Dell, SSH, Pi-hole + Unbound, Wireguard VPN opérationnel.
2️⃣
Phase 2 — Virtualisation
Proxmox VE sur PB63, première VM Debian, Nextcloud + Traefik reverse proxy, Vaultwarden.
3️⃣
Phase 3 — Monitoring & Dev
Prometheus + Grafana, Gitea + Woodpecker CI pour les projets personnels.
4️⃣
Phase 4 — Sécurité
Ansible depuis le Nitro, Wazuh SIEM avec agents sur toutes les machines.
5️⃣
Phase 5 — VLANs & k3s
Configuration des VLANs sur le switch manageable, cluster Kubernetes k3s.

💡 Compétences mobilisées

🔧 Virtualisation : Proxmox VE • KVM • LXC  |  🌐 Réseau : VLANs • DNS • VPN • Reverse Proxy (Traefik)  |  🛡️ Sécurité : SIEM • IDS/IPS • Fail2ban • UFW  |  📦 DevOps : Docker • Gitea • CI/CD • Ansible
